ECOSISTEMA MACROXEL PUNTO DE VENTA - DEMO v1.0.9 PROTEGIDO

CORRECCIÓN DE NARRACIÓN
- Cola única y secuencial de voz: una narración debe terminar realmente antes de iniciar la siguiente.
- Los textos largos se dividen en fragmentos naturales para evitar cortes del motor de voz del navegador.
- Se eliminaron temporizadores por longitud que podían adelantar el recorrido.
- Las alertas operativas por voz no interrumpen el recorrido guiado.
- Login, bienvenida, explicación de módulos, Ventas, Pedidos y Libro de Antibióticos usan la misma cola.
- Pausar/Reanudar conserva el punto actual. Finalizar explicación y doble clic en el logo son los únicos cortes intencionales.
- Las claves de estado avanzaron a v109 para que la corrección se aplique aun si el navegador conserva datos de una versión anterior.
